# Contract fixtures

Generated by `uv run python packages/contracts/scripts/make_fixtures.py` (deterministic: two
runs produce identical files). Every file is validated against the schema while it is
written, and again by both test suites (`index.json` maps each file to its definition).

**The runs are synthetic.** The runner does not exist before T06, so they are produced by
a scripted simulator, not recorded. Token counts are in the range the T00 spike observed.
Costs use prices that reproduce the CLI's `costUSD` exactly. The real `stream-json`
recordings from T00 are in `runner/tests/fixtures/stream-json/`. Use those for the adapter
(T04) and these for everything downstream of the adapter.
